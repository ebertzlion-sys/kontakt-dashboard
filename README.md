# Vertriebs-Cockpit

Persönliches Kontakt-Dashboard mit Login, Team-Freigaben, Kalender, To-Dos und Buchungen.

- `index.html`: die Website (GitHub Pages)
- `schema.sql`, `kalender.sql`: Datenbank-Einrichtung für Supabase

Die Kontaktdaten liegen nicht in diesem Repository, sondern in Supabase, geschützt durch Login und Row Level Security.
